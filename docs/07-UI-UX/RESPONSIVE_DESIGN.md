# Responsive Design & Breakpoint Standards

## 1. Breakpoints
- **Mobile** (`< 640px`): Single column layout, collapsed bottom drawer for calling notes, stackable action buttons.
- **Tablet** (`640px - 1024px`): Collapsible sidebar navigation, 2-column KPI grids, scrollable data tables.
- **Desktop** (`> 1024px`): Persistent sidebar, multi-column dashboard grid, slide-over modals for calling dossiers.

## 2. Touch & Accessibility Standards
- Minimum tap target size: `44px x 44px`.
- High contrast ratio (WCAG 2.1 AA compliant) on all text over backgrounds.
