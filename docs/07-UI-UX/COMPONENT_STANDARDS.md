# Reusable UI Component Standards

## 1. Core Component Library
- **Button**: Variants (`primary`, `secondary`, `danger`, `outline`, `ghost`), sizes (`sm`, `md`, `lg`), loading spinner state.
- **Badge**: Status badges for leads (`NEW`, `CONTACTED`, `INTERESTED`, `PENDING_REVIEW`, `APPROVED`, `REJECTED`).
- **DataTable**: Built-in sorting, pagination, search input, empty state, and column visibility.
- **Modal & Drawer**: Accessible slide-over drawers for calling logs and patient dossiers.
- **StatCard**: Reusable KPI card with title, metric, change delta, and icon.
