# User Experience (UX) Guidelines & Tele-Sales Ergonomics

## 1. High-Velocity Calling Ergonomics
- **One-Click Calling**: Clicking "Call" opens the drawer instantly with pre-populated patient details.
- **Keyboard Shortcuts**: Number keys or hotkeys for rapid outcome selection (`1: Interested`, `2: Follow-up`, `3: Busy`, `4: No Answer`).
- **Zero Refresh**: Instant optimistic state update upon logging a call without full page reload.

## 2. Decision Friction Reduction
- Pending Reviewers and Approvers see all patient context, call history, and pricing on a single consolidated view to avoid tab hopping.
