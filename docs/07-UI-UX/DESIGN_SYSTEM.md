# Design System Specification: Melayurveda Enterprise

## 1. Brand Palette & Color Tokens
- **Primary Forest Green**: `#14532D` (Deep Forest - Brand Anchor)
- **Secondary Sage Green**: `#166534` (Hover / Nav Accent)
- **Accent Gold / Amber**: `#CA8A04` / `#EAB308` (CTAs, Badges, Highlights)
- **Background Slate**: `#F8FAFC` (Soft modern background, high contrast)
- **Card White**: `#FFFFFF` (Pure white card surfaces)
- **Text Primary**: `#0F172A` (Dark charcoal for extreme readability)
- **Text Secondary**: `#64748B` (Muted slate for labels and timestamps)
- **Status Colors**:
  - Success / Approved: `#15803D` (Emerald)
  - Warning / Pending: `#D97706` (Amber)
  - Danger / Rejected: `#DC2626` (Crimson)
  - Info / Review: `#2563EB` (Royal Blue)

## 2. Typography
- **Primary Font Family**: `Inter`, `Plus Jakarta Sans`, system-ui.
- **Hierarchy**:
  - Display Title: 24px - 30px Bold (Dashboard Overview)
  - Section Header: 18px - 20px SemiBold
  - Body Text: 14px Regular
  - Data / Table Cells: 13px - 14px Medium
  - Microcopy / Badges: 11px - 12px SemiBold Uppercase

## 3. Elevation & Surfaces
- Clean, flat aesthetic with subtle drop shadows (`shadow-sm`, `shadow-md`).
- Rounded corners: `rounded-lg` (8px) for buttons and inputs, `rounded-xl` (12px) for cards.
