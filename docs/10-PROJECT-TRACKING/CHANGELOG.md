# Changelog: MELAYURVEDA CRM

All notable changes to the MELAYURVEDA Enterprise CRM project will be documented in this file.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), adhering to Semantic Versioning.

## [0.1.0] - 2026-11-20
### Added
- Complete project documentation suite encompassing 71 markdown specification files across 11 structured directories.
- Master Implementation Prompt archiving and system architecture specifications.
- Five dedicated panel specifications: Super Admin, Salesperson, Pending Review, Approval Authority, and Management.
- End-to-end Lead Lifecycle state machine definition with strict transition invariants.
- Strict architectural enforcement specification for Lead Source Privacy (salesperson isolation).
- Complete PostgreSQL Prisma ORM schema definition featuring 18 normalized relational models, enum types, composite indexes, and transactional boundaries.
- 15 API Bundle roadmap and REST conventions specification (/api/v1).
- Comprehensive Security Architecture including Argon2id password hashing, rotating JWT refresh tokens, and RBAC/ABAC guards.
- Design System tokens (Forest Green, Gold accents, Modern Typography) and UI/UX guidelines.
- Automated testing strategy covering Unit, API Integration, Security Pen-testing, and Playwright E2E suites.
- Containerization and deployment blueprints for Docker, PostgreSQL, and production cloud hosting.
